# Photo Storage App

An Android application written in Kotlin for storing and managing photos on the device.

## Features
- Select and save photos through the app interface
- View saved photos in a RecyclerView
- Update or delete stored photos
- Store image data locally using SQLite

## Tech stack
Kotlin, Android SDK, Android Studio, SQLite (`SQLiteOpenHelper`), RecyclerView.

## Running locally
Open this directory as a project in Android Studio, sync Gradle, and run on an Android emulator or device.
